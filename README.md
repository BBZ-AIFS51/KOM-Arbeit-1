Interaktive Lern-App (Spickzettel, Quiz mit Schwachpunkt-Auswertung, Probeklausur mit Musterlösungen)
zu Sender-Empfänger-Modell, Watzlawicks 5 Axiomen, Vier-Seiten-Modell und Ich-Botschaft.

**Live:** https://bbz-aifs51.github.io/KOM-Arbeit-1/

- `index.html` – die App (eigenständige HTML-Datei, läuft auch lokal per Doppelklick)
- `Lernzettel_Kommunikationsgrundlagen.*` – Lernzettel (Markdown, Word, PDF, draw.io)
- `Uebungsblatt_Kommunikationsgrundlagen_IT_Systemadministration.*` – Übungsblatt
